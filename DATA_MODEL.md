# DATA_MODEL.md — PromptHub Enterprise

Complete reference of every table, column, relationship, constraint and enumerated value in the database.

---

## Overview

PromptHub uses SQLAlchemy 2.0 ORM with `create_all` for DDL. Two database backends are supported:

- **SQLite** (default) — file at repo root `prompthub.db`, zero-setup
- **PostgreSQL** — set `DATABASE_URL` env var

18 tables organized in five domain groups:

```
users ──┬── prompts ──┬── prompt_versions
        │             ├── prompt_inputs
        │             ├── prompt_ratings
        │             ├── prompt_favourites
        │             ├── prompt_shares
        │             ├── prompt_reviews
        │             ├── knowledge_sources
        │             ├── prompt_executions
        │             └── approval_requests
        │
        ├── documents ── document_chunks
        ├── workflows ──┬── workflow_steps
        │               └── workflow_executions
        ├── governance_policies
        ├── compliance_violations
        ├── audit_events
        └── seq_counters
```

---

## ID Format

All business-facing IDs are sequential, zero-padded strings generated by `backend/app/ids.py` using the `seq_counters` table:

| Entity | Prefix | Width | Example |
|--------|--------|-------|---------|
| Prompt | PROMPT | 6 | PROMPT-000001 |
| Execution | EXEC | 8 | EXEC-00000001 |
| Workflow | WORKFLOW | 6 | WORKFLOW-000001 |
| Workflow run | WRUN | 8 | WRUN-00000001 |
| Policy | POLICY | 5 | POLICY-00001 |
| Approval | APPROVAL | 5 | APPROVAL-00001 |
| Audit event | EVT | 8 | EVT-00000001 |
| Document | DOC | 6 | DOC-000001 |
| User | USER | 4 | USER-0001 |
| Violation | VIO | 6 | VIO-000001 |
